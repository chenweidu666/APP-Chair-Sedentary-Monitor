# 安装与开机自启

## 1. 依赖

```bash
cd APP-Chair-Sedentary-Monitor
pip install -r requirements.txt          # bleak（BLE 必需）
pip install -e .                          # 可选：装成本包，得到 chair-monitor 命令
```

协议部分复用同一条链路上的开源库
[APP-WT9011DCL-BT50-Linux](https://github.com/chenweidu666/APP-WT9011DCL-BT50-Linux)
（`wt9011` 包，包含 BLE 连接、协议解析、电量读取、自动重连）。`install.sh` 会自动安装它：
本地存在 `~/Linux-App/01/APP-WT9011DCL-BT50-Linux` 时用本地 `-e`，否则从 GitHub 装。

## 2. 一键安装（开机自动连接）

```bash
./install.sh              # 常驻检测 + systemd 用户服务（推荐）
./install.sh --tray       # 托盘界面模式（登录后自启 GUI）
./install.sh --uninstall  # 卸载
```

安装做了什么（都在用户目录，不需要 sudo）：

| 位置 | 内容 |
|---|---|
| `~/.local/bin/chair-monitor` | 启动器（把找到的 Python 与仓库路径写死，PATH 最小也能跑） |
| `~/.config/systemd/user/chair-monitor.service` | 常驻服务：`chair-monitor run`，`Restart=always`，开机自启 |
| `~/.config/autostart/chair-monitor-tray.desktop` | 仅 `--tray` 模式下写入 |
| `~/.local/share/icons/hicolor/.../chair-monitor.svg` | 图标 |

**开机自动连接**由 `Restart=always` + 内部重连双保险实现：
服务启动 → 找设备（配置里的 MAC，或扫描 `WT/BWT` 前缀）→ 连上开始检测；
没连上就每 5 s 重试；连上后掉线自动重连。**椅子/传感器断电再上电也不用人管。**

想让"未登录也运行"（比如挂在服务器/无头机器上）：

```bash
sudo loginctl enable-linger $USER
```

## 3. 上机四步

```bash
# ① 把传感器贴到椅背背面中上部（硬质固定），确认能连上
chair-monitor status --addr <MAC>

# ② 第一次装完，让椅子空着，重建空椅基线
chair-monitor mark-empty

# ③ 看实时状态（无人/有人、已坐多久、下次提醒、电量、倾角、呼吸频率）
journalctl --user -u chair-monitor -f

# ④ 用真实数据调阈值（强烈建议，见 docs/久坐检测原理.md 第 6 节）
chair-monitor record --label empty --seconds 60 --csv empty.csv
chair-monitor tune empty.csv
```

## 4. 常用操作

```bash
systemctl --user status chair-monitor      # 服务状态
systemctl --user restart chair-monitor     # 改完配置重启
systemctl --user stop chair-monitor        # 临时停
chair-monitor tray                         # 托盘界面（状态/久坐时长/电量/暂停/清零）
chair-monitor sim --scenario "empty:25,sit_impact:1.2,leaning:90,empty:60"  # 无硬件演示
python3 -m unittest discover -s tests -v   # 17 项算法单测（合成数据）
```

配置文件：`~/.config/chair-monitor/config.json`（设备地址、安装位置、久坐策略、阈值覆盖）：

```json
{
  "address": "EE:AA:BB:CC:DD:EE",
  "mount": "backrest",
  "sitting_limit_min": 45,
  "repeat_min": 15,
  "standing_reset_min": 2,
  "notify": true,
  "overrides": { "tilt_on_deg": 3.0 }
}
```

## 5. 消息通知

提醒走 `notify-send`（GNOME 系统通知）。如果 `systemctl --user` 的服务里通知不弹：

- 确认服务是**用户级**（`--user`）且你已登录桌面会话；
- `systemctl --user show-environment | grep DBUS` 有输出；
- 无桌面场景（无头机器）会自动退化为写日志，不报错。

## 6. 故障排查

| 现象 | 处理 |
|---|---|
| 服务起了但一直"未连接" | `chair-monitor status --addr <MAC>` 手动试；BLE 是独占的，手机 App / GNOME 蓝牙面板连过要先断开（详见 WT9011 项目的排错手册） |
| 长期误报"有人" | 椅子空着跑 `record --label empty` + `tune`，按建议调高 `motion_on_g` / `breathing_min_amp_g` |
| 坐了但一直"无人" | 多半是坐直不靠椅背且传感器没感受到呼吸：把传感器挪到椅背**变形/受压更明显**的位置（避开腰垫软区），或改用 `mount: seat` |
| 想暂停提醒 | 托盘菜单"暂停提醒 30 分钟"，或 `notify: false` + 重启服务 |
