# 久坐检测原理：怎么判断"有人坐 / 没人坐"

> 传感器贴在**椅背**（也支持座板下方，`mount: backrest | seat`）。本文说明判据、
> 阈值、为什么这么设计，以及纯 IMU 方案的已知边界。

## 1. 三个判据（缺一不可）

| 判据 | 空椅表现 | 有人表现 | 作用 |
|---|---|---|---|
| **① 倾角偏移 Δθ** | 只有温漂，实测 <0.5° | 椅背受压后倾，通常 **2–10°** | 主判据，最快最稳 |
| **② 呼吸/微动** | 只有传感器噪声，0.15–0.55 Hz 无周期成分 | 靠背受压随呼吸起伏，实测 0.2–0.4 Hz、幅度 ~0.005 g | **补"坐直不靠椅背"的漏判** |
| **③ 落座/起身瞬态** | 无 | 冲击 `|acc|-1g > 0.06`、角速度尖峰 1–2 s | 让状态切换**及时**，不必等几十秒 |

为什么不能只用其中一个：

- 只看 ①：人坐直不靠椅背 → 椅背零负载 → Δθ≈0 → 误判"没人"。
- 只看 ②：风扇/空调吹椅背、地板震动 → 周期性伪信号 → 误判"有人"。
- 只看 ③：有人路过碰一下椅子 → 冲击 → 误判"有人"。

所以判"有人"= ① **或**（② 且运动高于空椅噪声底）**或**（③ 且 ① 已偏转）；
判"没人"= 三项全部回落**并持续 30–45 s**（迟滞 + 驻留，防抖动）。

## 2. 自动学噪声底（关键工程点）

不同椅子/安装/环境噪声差一个数量级，**写死阈值一定两头错**。所以：

1. 启动后 20 s（`learn_seconds`）自学习：记录空椅姿态基线 `g_ref`、运动噪声底
   `noise_rms`、角速度噪声底 `noise_gyro`；
2. 运行期阈值 = `max(配置值, 噪声底 × 系数)`：
   - 运动进入 ≥ 噪声底 ×2.5，退出 ≥ ×1.6（退出倍率要小，否则永远退不出"有人"）
   - 角速度上限 ≥ 噪声底 ×2
   - 呼吸幅度门槛 = `max(0.002 g, 噪声底 ×2.2)`，**上限 2.2×配置值**
3. 呼吸噪声底只用"明显低于门槛"的幅度学习。

> 第 3 条踩过坑：一开始无论何时都学呼吸噪声底，结果"坐直的人"的呼吸被当成噪声学进底噪，
> 门槛被抬高到超过真实呼吸 → **自我掩蔽**，永远检不出人。单测 `test_upright_*` 就是这个回归。

## 3. 状态机

```
        ┌───────────── 20 s 自学习 ─────────────┐
        ▼                                      │
   UNKNOWN ──(空椅证据 ≥2 s)──► EMPTY ◄─────────┘
        │                        │  ▲
        │                   ①/②/③成立且持续 ≥2 s
        │                        ▼  │ 无人证据持续 ≥30 s
        └──(数据中断 >3 s)──► OCCUPIED ──(起身瞬态 + 无呼吸 + ≥10 s)──► EMPTY
```

- **证据累计带容错**：单帧毛刺（空椅噪声偶发超阈）不会清零计时，只有证据缺失超过 5 s
  才归零。实测空椅角速度噪声会间歇性冲高，不这样做驻留计时永远凑不满。
- **数据中断**（BLE 掉线 >3 s）→ UNKNOWN：**暂停久坐计时，但不判"没人"**，
  避免"拔了传感器就把 45 分钟久坐清零"。

## 4. 久坐提醒策略

| 参数 | 默认 | 说明 |
|---|---|---|
| `sitting_limit_min` | 45 | 连续坐满即提醒 |
| `repeat_min` | 15 | 之后每 15 分钟再提醒 |
| `standing_reset_min` | 2 | 起身**累计** 2 分钟才算"活动过"并清零；去倒杯水 40 秒不清零 |

## 5. 已知边界

| 情况 | 表现 | 说明 |
|---|---|---|
| 椅子上放重物/挂包 | 会判"有人" | 纯 IMU 无法区分"人"与"重物"，若在意需加压力传感 |
| 硬木椅（座板/椅背几乎不变形） | 灵敏度下降 | 倾角信号弱，只能靠呼吸与微动；建议改贴椅背框架或加压力片 |
| 完全不接触椅背且极度静止 | 依赖呼吸判据，检出慢（~20–40 s） | 呼吸需要 25 s 窗口才能分辨 0.3 Hz，无法更快 |
| 风扇/空调直吹传感器 | 可能误报 | 调整安装位置避开气流，或调高 `breathing_min_amp_g` |
| 椅子被推动/旋转 | 瞬态干扰 | 由"①已偏转"与驻留时间过滤 |

**想更可靠**：加一片 **FSR 压力片**（约 ¥10，串电阻接 ADC/USB）或**称重传感器 HX711**
放在座板下，与 IMU 做"与"融合，可把"人 vs 重物"彻底分开。`occupancy.py` 的判据是纯函数，
接一路 `pressure` 输入即可扩展。

## 6. 调参流程（上真机后必做）

```bash
# 1) 椅子空着，采 60 s
chair-monitor record --label empty   --seconds 60 --csv empty.csv
# 2) 自己坐上去+靠椅背，采 60 s（再采一段"坐直不靠"的）
chair-monitor record --label leaning --seconds 60 --csv leaning.csv
chair-monitor record --label upright --seconds 60 --csv upright.csv
# 3) 让它推荐阈值
chair-monitor tune empty.csv
```

`tune` 会打印各标签下 `tilt_deg / motion_rms / gyro_mean / breath_amp` 的中位数与 p95，
并给出建议阈值（空椅 p95 的 1.5–2 倍）。把结果写进
`~/.config/chair-monitor/config.json` 的 `overrides`：

```json
{ "mount": "backrest", "overrides": { "motion_on_g": 0.02, "breathing_min_amp_g": 0.004 } }
```

改完 `systemctl --user restart chair-monitor` 生效。
